# 🏡 Airbnb Data Analysis & Tableau Dashboard

This project focuses on understanding Airbnb listing behavior across various zipcodes by analyzing pricing trends, yearly revenue, and bedroom distribution.  
Visualizations were built using **Tableau Public**, and data processing was done in **Excel**.

---
